# Box Shared Link Resolver

共有リンク https://ドメインA/s/xxxx から実体のフォルダ/ファイルを探し、https://コラボレーション先のドメイン/folder/ID に遷移します。トークン不要（コラボレーション先ドメインのログイン状態を利用）。

## インストール
1. ZIPを展開
2. chrome://extensions → 右上「デベロッパーモード」ON
3. 「パッケージ化されていない拡張機能を読み込む」→ 展開したフォルダを選択
4. 拡張機能の「詳細」→「拡張機能のオプション」でコラボレーション先のドメインを設定・保存

## 使い方
- コラボレーション先のドメインにログインしたタブを開いておく（なければ自動で開きます）
- アイコン → 共有リンクを貼り付け →「解決して開く」
- またはリンクを右クリック →「Box共有リンクを解決して開く」

## 仕組み
設定の検索エンドポイント（Box Web内部API）をページ順に呼び、応答の items から共有リンクが一致するアイテムの ID と名前を探します。
ポップアップに通信ログが出ます。Box内部APIは非公開のため、動かない場合はブラウザのF12→ネットワークでBox検索時のURLを確認し、オプションの「検索エンドポイント」に設定してください。
