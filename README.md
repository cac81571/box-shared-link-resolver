# Box Shared Link Resolver

共有リンク https://ドメインA/s/xxxx から実体のフォルダ/ファイルを探し、https://ドメインB/folder/ID に遷移します。トークン不要（ドメインBのログイン状態を利用）。

## インストール
1. ZIPを展開
2. chrome://extensions → 右上「デベロッパーモード」ON
3. 「パッケージ化されていない拡張機能を読み込む」→ 展開したフォルダを選択
4. 拡張機能の「詳細」→「拡張機能のオプション」でドメインBを設定・保存

## 使い方
- ドメインBにログインしたタブを開いておく（なければ自動で開きます）
- アイコン → 共有リンクを貼り付け →「解決して開く」
- またはリンクを右クリック →「Box共有リンクを解決して開く」

## 仕組み
1. Boxタブ内で /s/共有ID を取得し、リダイレクト先URLやHTMLの "itemID" を探す
2. だめなら設定の検索エンドポイント（Box Web内部API）を順に呼び、応答中で共有IDを含むアイテムのIDを探す
ポップアップに通信ログが出ます。Box内部APIは非公開のため、動かない場合はブラウザのF12→ネットワークでBox検索時のURLを確認し、オプションの「検索エンドポイント」に設定してください。
