# Box Shared Link Resolver

共有リンク `https://コラボ先ドメイン/s/xxxx` から実体のファイル／フォルダを探し、`https://自社ドメイン/file/ID` または `/folder/ID` を開きます。OAuth トークンは使いません。自社 Box にログインしたタブの Cookie で、Web 内部 API を呼びます。

## インストール

1. ZIP を展開する
2. `chrome://extensions` で右上の「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」で展開したフォルダを選ぶ
4. 「拡張機能のオプション」で自社ドメインとコラボ先ドメインを保存する

初期値は `config.js` の `DEFAULTS` です。

## 設定

| 項目 | 内容 |
| --- | --- |
| 自社ドメイン | 検索と遷移先（例: `my-corp.ent.box.com`） |
| コラボ先ドメイン | 共有リンクのホスト（例: `customer-corp.ent.box.com`） |
| 検索エンドポイント | Box Web 内部 API。`{folderid}` `{updatedDays}` `{page}` を実行時に置換 |
| フォルダ ID | 検索の起点。`0` ですべてのファイル |
| 更新日：過去〇日 | カタログに無いときの検索範囲（初期値 7） |
| カタログ収集：過去〇日 | 「収集」で取る範囲（初期値 365） |
| カタログ登録先フォルダ ID | `box-shared-link-catalog.json` を置くフォルダ。空なら検索対象のフォルダ ID。他ユーザもアクセスできるフォルダにする |

「収集」は過去1年分など大量の共有リンク（共有ID、ファイル/フォルダ ID、名前、更新日）を端末に集めます。「Box に登録」で登録先フォルダへ JSON として書き込みます。同じフォルダを見られる他のユーザは「Box から取り込む」で自分のカタログにできます。失敗したときは「JSON を保存 / 読み込む」で手動共有できます。収集中は設定画面と Box のタブを閉じないでください。

## 使い方

- 自社 Box（または `app.box.com`）にログインしたタブを表示した状態で使う。カタログ取り込みや検索時に Box が開いていないと「Box にログインしてください」と出る
- 拡張アイコン → 共有リンクを貼り付け →「開く」（Enter でも同じ）
- クリップボードが `https://コラボ先ドメイン/s/` で始まるときだけ、入力欄に初期表示する
- リンクや選択テキストを右クリック →「Box共有リンクを解決して開く」

見つかると、ファイル／フォルダ名を出してそのページを開き、3 秒後にポップアップを閉じます。

## 検索の流れ

検索結果のうち、共有リンクが付いている項目だけをカタログに残します。日付はファイルの更新日（`contentUpdated` / `date`、Unix 秒）です。

- **開く**: その日まだなら先にカタログをストレージへ取り込む。ストレージを検索してあればすぐ開く。無ければ設定の過去〇日分を検索し、見つかった時点で開く
- 「開く」と設定のカタログ処理は同時には走らない

## 仕組み

表示中の Box タブで、次の内部 API をページ順に呼びます（間隔は約 0.4 秒）。

`/app-api/enduserapp/folder/{folderid}/search?sortColumn=date&sortDirection=desc&updatedTime={updatedDays}&page={page}`

`items[].sharedLink` が共有 ID と一致する項目の ID と名前を使います。この API は非公開です。動かないときは、ブラウザの開発者ツールのネットワークで Box 検索時の URL を確認し、設定の「検索エンドポイント」を合わせてください。
